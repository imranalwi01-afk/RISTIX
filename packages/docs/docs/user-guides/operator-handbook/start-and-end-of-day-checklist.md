# Start and End of Day Checklist

## Start of Day Checklist

- log in to the correct environment and tenant
- confirm the dashboard loads successfully
- confirm the sidebar matches your assigned role
- review urgent pending approvals
- review any overnight failures, empty reports, or user complaints
- check the report or module you are responsible for that day

## Midday Control Points

- record request IDs for all approval-driven changes
- avoid duplicate submissions when a request is already pending
- verify approved changes in the live list after refresh
- keep screenshots or evidence for any issue that may need escalation

## End of Day Checklist

- review all pending requests you own or submitted
- hand off any unresolved request IDs to the next reviewer or admin
- record rejected, delegated, or information-requested items
- note any broken filters, exports, or report anomalies
- confirm the day’s evidence is saved if QA or UAT is in progress

## Daily Exceptions to Record

- `401` authentication issues
- `403` approval eligibility issues
- `409` pending conflict issues
- approved changes not visible in live data
- report pages that remain empty with valid filters

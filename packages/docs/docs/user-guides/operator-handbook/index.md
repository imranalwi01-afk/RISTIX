# Operator Handbook

This handbook is the day-to-day operating manual for IFRS 9 platform users.

Use it when you need:

- a practical routine for daily operations
- role boundaries and handoff rules
- approval and escalation guidance
- opening and closing checklists

## Recommended Reading Order

1. [Daily Operations Handbook](./daily-operations)
2. [Role and Responsibility Matrix](./role-and-responsibility-matrix)
3. [Approval and Escalation Playbook](./approval-and-escalation-playbook)
4. [Start and End of Day Checklist](./start-and-end-of-day-checklist)

## When to Use the Handbook Instead of a User Guide

Use the operator handbook when you want guidance such as:

- what to check first when starting work
- who should perform a task
- who should approve it
- what to do when a request is stuck
- what evidence should be collected

Use the task-based user guides when you already know the task and only need the exact page-level workflow.

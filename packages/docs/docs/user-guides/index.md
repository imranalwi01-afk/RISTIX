# User Guides

This section is the operational guide for IFRS 9 platform users.

Use these documents when you want to complete a business task in the application, not when you want to inspect code or APIs.

## How to Navigate This Portal

Choose one of these reading paths:

- `Start Here` if you are a new user or QA tester
- `Operator Handbook` if you want a daily operating manual
- `By Role` if you want guides for Maker, Approver, or Admin responsibilities
- `By Task` if you want to perform setup, approval, audit, or reporting work
- `By Scenario` if you want an end-to-end walkthrough from submission to validation
- `QA/UAT Packs` if you need evidence-oriented execution templates

## Writing Style of This Section

Each user guide is task-based and follows the same structure:

- purpose
- who should use it
- prerequisites
- step-by-step actions
- expected result
- common errors and next actions

If a page in this section feels too technical, it should usually be moved to architecture or API documentation instead.

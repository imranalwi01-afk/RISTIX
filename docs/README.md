# IFRS9 Project Documentation

The technical documentation for this project has been migrated to the official documentation package for better integration and professional display.

## 🚀 Official Documentation: [packages/docs](../packages/docs/)

All technical materials, specifications, and reports are now managed within the [**packages/docs**](../packages/docs/) monorepo package. This is a Docusaurus-based documentation site.

### **How to View & Contribute**
1.  Navigate to the `packages/docs` directory.
2.  Follow the instructions in the [packages/docs/README.md](../packages/docs/README.md) to run the development server or build the site.
3.  Add new technical markdown files to the `packages/docs/docs/` directory.

### **Current Organization (within packages/docs/docs/)**
- **Architecture**: System design, database architecture, and notifications.
- **Operations**: Setup guides, development workflows, and compliance.
- **Specifications**: API references, schemas, and query specifications.
- **Reports**: Functional analysis, progress reports, and implementation summaries.
- **Reference**: Checklists, large static reports, and schema files.

## 📂 Non-Technical Resources

- **[Data](./data/)**: Contains sample and reference data files (e.g., CSV imports) used for testing and development.

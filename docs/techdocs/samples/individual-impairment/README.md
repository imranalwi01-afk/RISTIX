# Individual Impairment Samples

This folder keeps reference-only files for manual QA and tech-spec alignment.

- `DCF_SAMPLE_NON_ZERO.csv`: sample DCF upload rows with non-zero principal and interest.
- `DCF_LOSS_CASE.csv`: sample DCF upload rows that produce a loss/provision scenario.
- `IA_FLOWS.sql`: SQL reference extracted from the Individual Assessment flow for watchlist, reports, review, DCF, and approval validation.

These files are not runtime inputs and should not be imported by application code.
